# Smilecare

This project was generated with Spring Boot version 3.2.0 using Maven.

## Development server

Run mvn spring-boot:run for a dev server. The application will be accessible at http://localhost:8089/api. The server will automatically reload if you change any of the source files.

## Code scaffolding

Run mvn archetype:generate to generate new project components or use your IDE to create new classes, controllers, services, or entities. You can also manually create files for controllers, services, models, or enums in the src/main/java directory.

## Build

Run mvn clean install to build the project. The build artifacts will be stored in the target/ directory.

## Running unit tests

Run mvn test to execute the unit tests via JUnit.

## Running end-to-end tests

Run mvn verify to execute integration tests or end-to-end tests via a platform of your choice. To use this command, you need to first add a package that implements end-to-end testing capabilities, such as Spring Boot Test.

## Further help

To get more help on Maven, use mvn --help or check out the Maven Official Documentation. For Spring Boot, refer to the Spring Boot Reference Documentation.
